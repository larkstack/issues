# Contributing to Lark

Thank you for your interest in Lark.

## Important: No Code Contributions

Lark is developed privately and implemented exclusively by automated AI agents.

---

## How You Can Contribute

You can contribute by:

- Reporting reproducible bugs
- Suggesting well-defined features
- Providing minimal reproduction examples
- Improving clarity of issue reports

---

## Bug Report Requirements

A good bug report includes:

- Lark package (`lark`, `lark_ui`, `lark_lints`, `lark-vscode`)
- Version number
- Dart/Flutter version
- Operating system
- Exact reproduction steps
- Expected behavior
- Actual behavior
- Logs or stack traces (if available)

Issues missing critical details may be labeled `needs-info` and closed if not updated.

---

## Feature Requests

Feature requests should include:

- Clear problem statement
- Why the feature is needed
- Proposed API or behavior (optional but helpful)
- Use case examples

---

## Issue Lifecycle

Issues typically move through these states:

- `needs-triage`
- `needs-info`
- `accepted`
- `planned`
- `done`
- `wontfix`
- `duplicate`

Not all requests will be accepted.

---

## Behavior Expectations

Please remain respectful and constructive.  
Abusive or hostile behavior may result in moderation.

Thank you for helping improve Lark.
