# Code of Conduct

This repository is dedicated to constructive and professional collaboration.

## Expected Behavior

- Be respectful and clear.
- Focus on reproducible technical issues.
- Provide actionable details.

## Unacceptable Behavior

- Harassment
- Personal attacks
- Spam
- Repeated low-quality or off-template reports

Moderation actions may include:

- Comment removal
- Issue closure
- Interaction limits

This repository exists for structured issue reporting only.
